# RideLog Pilot v1.2

Release: 2026-08-13

RideLog Pilot は、タクシー・ハイヤー・Uberなどのプロドライバー向け乗務記録アプリのパイロット版です。

## v1.2 Improvements

- 乗車後に入力した乗車地が履歴へ反映されない問題を修正
- 画面上部に「累計売上・乗車回数・乗車・降車」を固定表示
- 修正画面の人数を、タップ後すぐ選択できる方式に変更
- 履歴の乗務記録に通し番号を追加
- 入力を忘れた乗務を、履歴の途中へ割り込み追加できる機能を追加
- 降車保存後、乗車種別を「Uber」、人数を「1名」へ自動リセット
