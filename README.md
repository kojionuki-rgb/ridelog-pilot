# RideLog Pilot v1.6

Release: 2026-09-20

タクシードライバー向けの、シンプルな乗務記録・乗務日報アプリです。

## v1.6 Improvements

- ホーム画面の内訳を「Uber / 手上げ / その他」に変更

- 各カテゴリーに合計金額と乗車回数を表示

- 乗車種別「駅」を「駅、乗り場」に変更

- 本日の乗車記録で未入力項目を赤枠表示

- 乗車中は「乗車」、待機中は「降車」ボタンを一回り縮小し、次に押すボタンを明確化

- v1.5で追加した個人タクシー向け運転日報機能を継続

## Ride Log

乗車ごとに以下の情報を記録できます。

- 乗車種別

- 人数

- 乗車地

- 降車地

- 乗車時刻

- 降車時刻

- 料金

- 高速料金

- メモ

## Dashboard

本日の営業状況を自動集計します。

- 累計売上

- 乗車回数

- Uber

- 手上げ

- その他

- 各カテゴリーの売上金額

- 各カテゴリーの乗車回数

- 本日の売上目標と進捗

## Driver Information

乗務情報として以下を入力できます。

- 日付

- 天候

- 乗務員名

- 車両番号

- 出庫時刻

- 帰庫時刻

- 本日の売上目標

## Daily Report

個人タクシー向け「運転日報」PDF / 印刷テンプレートに対応しています。

RideLogの乗車記録から、

- 回数

- 人員

- 乗車地

- 降車地

- 降車時刻

- 運賃額

などを自動転記します。

営業回数・営業収入・乗車人数も自動集計します。

また、

- 睡眠時間

- 免許期限

- 車検

- メーター

- 燃料

などの日報固有項目も入力できます。

従来のRideLog PDF / CSV機能も継続しています。

## Data

乗務データはブラウザ内に保存されます。
