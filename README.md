# RideLog Pilot v1.4
Release: 2026-08-18

## Improvements
- 乗車種別の並び順を変更
  - Uber → 手上げ → 駅 → ホテル → 空港 → GO → DiDi → ハイヤー → その他
- 乗車種別の選択肢に色付き四角を追加
  - Uber: 黒
  - 手上げ: 紫
  - 駅: 緑
  - ホテル: 黄
  - 空港: 水色系
  - GO: 青
  - DiDi: オレンジ
  - ハイヤー: グレー
- 上部固定バーの累計売上を2段階大きく表示
- 上部固定バーの乗車回数を1段階大きく表示

## Notes
- v1.3までの乗車地保存、履歴通し番号、途中追加、画面常時表示、PDF/印刷改善などは継続しています。
